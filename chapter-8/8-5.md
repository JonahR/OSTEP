10ms time slice in highest queue. How often do I need to boost to guarantee 5% of the CPU?

Worst case is one long running process in the lowest queue an a continuous amount of new 10ms jobs. This will
starve the long running job. For Boost value B, every B milliseoncds, the job runs for 10ms.
10ms / B = 5%. B = 200ms. With a boost value of 200ms, we can guarantee 5% CPU time.
